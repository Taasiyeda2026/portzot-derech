# כרטיסי ״נושמות השראה״

תיקייה לריכוז קובצי הכרטיסים במסגרת ענף הפיתוח של המשחק.

- `shared-back.png` — גב הכרטיס האחיד לכל הנשים (מעלים פעם אחת).
- `women/` — קובצי הכרטיסים האישיים של כל אישה. מומלץ לתת שמות קבצים ייחודיים באנגלית.

אפשר להעלות PNG, JPG, WebP או PDF. שמות הקבצים צריכים להתאים לרשימה המאושרת.

**חשוב:** העלאת קבצים ל-GitHub אינה מייבאת אותם אוטומטית למאגר המשחק. האפליקציה משתמשת באחסון הפרטי של Supabase ויש לטעון או לסנכרן אליו את הקבצים באמצעות ממשק הניהול או תהליך יבוא מאובטח. קבצים במאגר GitHub ציבורי נגישים לציבור.
