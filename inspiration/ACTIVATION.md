# הפעלה בפרויקט Supabase הקיים

ההפעלה מיועדת לפרויקט `szinlhjuwyiyszdpsdop` בלבד. בעל המערכת אישר להקים בו את רכיבי המשחק, עם נתוני בדיקה מבודדים וללא פרויקט Supabase נוסף. נדרש אישור נפרד לפני פריסה או מיזוג לאתרים החיים.

## מצב מאומת

- הפרויקט פעיל עם PostgreSQL 17.6. נבדקה תאימות `realtime.send` ו־pg_cron.
- אין התנגשויות בשמות טבלאות/פונקציות המשחק, ואין bucket בשם `inspiration-cards` או job בשם `inspiration-retention`.
- נמצאה ירושת הרשאות UPDATE על sequences בברירות המחדל של הפרויקט. ה־Migration תוקן עם REVOKE מפורש למונה אירועי המשחק; נוספה בדיקת רגרסיה המדמה את ברירת המחדל החיה.
- נוספו סקריפטי השבתה ושחזור שאינם מוחקים נתונים. הם נבדקו פעמיים תוך שמירה על משימת cron בלתי קשורה ועל נתוני המשחק, Auth והדשבורד.
- עברו 83 בדיקות PostgreSQL מקומיות, 51 בדיקות ממוקדות ו־Deno check. בדיקות הדפדפן של המימוש הקיים מתועדות ב־QA.md; הן אינן תחליף לבדיקת ההפעלה החיה.

## חסימת החיבור

בוצעו שני ניסיונות `apply_migration`, ואחריהם ניסיון להחיל את אותו SQL המאושר ב־`execute_sql` בתוך טרנזקציה עם מגבלות זמן ונעילה. שלושתם חזרו עם `McpServerError: Invalid or expired requestState`. לא התקבלה סיבת דחייה של מדיניות אבטחה או הודעת שגיאה מתוך PostgreSQL.

בדיקת קריאה לאחר הכשלים אישרה שכל אלה עדיין חסרים: טבלאות המשחק, RPC, schema פרטי, bucket ו־job. לא בוצעו פריסת פונקציה או מיזוגי PR.

השוואת שבע טביעות metadata לפני ואחרי הראתה שאין שינוי בטבלאות/עמודות/הרשאות הקיימות, בפונקציות, באילוצים, במדיניות RLS, בטריגרים, בברירות המחדל או במשימות cron קיימות. נספרו 197 טבלאות ציבוריות קיימות, 423 policies ו־180 טריגרים של המשתמש. המדדים הללו הם בדיקת metadata; הם אינם גיבוי או טענה לסריקת כל תוכן השורות.

חיבור הקריאה תקין. נדרש לתקן או לחדש את חיבור הכתיבה של תוסף Supabase ולהריץ שוב את ההחלה המאושרת. אין סיבה להקים פרויקט חדש, לשנות סיסמאות או להוציא מפתח שרת מהפרויקט.

## פעולות מוכנות לאחר פתרון החסימה

1. להחיל את `supabase/migrations/20261024181538_inspiration_game.sql` בפרויקט הקיים. זו הרחבה מבודדת עם שש טבלאות ציבוריות חדשות, schema פרטי, פונקציות והגדרת מחיקת נתוני משחק בלבד. אין DML על נתוני הדשבורד או Auth.
2. לאמת RLS, REVOKE על טבלאות/מונה/RPC, הרשאות service_role ותזמון `inspiration-retention`, ולהשוות שוב את טביעות המערכת הקיימת.
3. **לאחר אישור פריסה:** לפרוס רק את `inspiration-game`, עם `verify_jwt=false` משום שקוד הפונקציה מאמת בעצמו staff JWT/אסימוני השתתפות. חבילת הפריסה כוללת `index.ts`, `handler.mjs`, `storage-bootstrap.mjs`, `deno.json`, `deno.lock`.
4. אתחול הפונקציה יוצר דרך Storage API רק bucket חסר בשם `inspiration-cards`, עם `public:false`, מגבלת 12 MiB ו־PNG/JPEG/WebP/PDF. בדיקת 409 מטפלת בהפעלות מקבילות. bucket קיים אינו משתנה; אחסון ציבורי או שגיאת הרשאות חוסמים את הפונקציה. מפתח השרת נשאר במשתני הסביבה המובנים של Supabase.
5. להריץ בדיקות אמיתיות מול הפונקציה באמצעות חדרי TEST-ONLY בעלי מזהים ייחודיים ותוקף קצר, ואז למחוק במפורש רק את מזהי הבדיקה. אסור להפעיל נתוני דוגמה במאגר התוכן הרשמי. בדיקת כניסה מוצלחת של עובדת דורשת את התחברות המשתמש בדפדפן; אין ליצור או לשנות חשבון עובד לצורך הבדיקה.
6. **לאחר אישור מיזוג ופריסה לאתרים:** למזג תחילה את [dashboard_system #2450](https://github.com/Taasiyeda2026/dashboard_system/pull/2450), להמתין להצלחת Deploy to GitHub Pages, ואז למזג את [portzot-derech #292](https://github.com/Taasiyeda2026/portzot-derech/pull/292) ולהמתין ל־Pages. שני המיזוגים מפעילים פריסה חיה אוטומטית. יש לבדוק SHA ו־CI מחדש לפני כל מיזוג.

כתובות לאחר פריסה מוצלחת:

- ניהול המשחק: `https://portzot-derech.org/inspiration/teacher.html`
- טעינת תוכן: `https://portzot-derech.org/inspiration/admin.html`
- גשר הזדהות: `https://taasiyeda2026.github.io/dashboard_system/inspiration-bridge.html`

אין כרגע תוכן מאושר טעון. לאחר ההפעלה ניתן להיכנס לניהול ולמאגר, אך פתיחת משחק אמיתי מותנית בטעינת הקלפים וההתאמות המאושרים.

## חזרה לאחור

- `sql/disable-game.sql`: מבטל רק את cron המשחק ואת EXECUTE של שלוש פונקציות שרת המשחק. אין DROP או DELETE. כל הנתונים והקבצים נשמרים. בקשה שכבר רצה יכולה להסתיים; אתחול ה־bucket עדיין בודק את האחסון הפרטי, אך פעולות המשחק חסומות.
- `sql/restore-game.sql`: מחזיר רק את אותן הרשאות ו־job אחד. שתי הפעולות דורשות אישור תפעולי לפני ביצוע.
- אחרי מיזוגי האתרים, rollback נעשה ב־PR עם revert של מזהי המיזוג בפועל, ללא force push או איפוס main. גרסאות הייצור לפני השינוי: דשבורד `6d22bb394c5cfede76a130e1ccaea865ed69ecc8`, קורס `4dd331e820437dc573dfefc7deec27543298e443`.
