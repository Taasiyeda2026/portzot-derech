# Domain images

התיקייה מיועדת רק לתמונות של עמודי התחומים.

## מעטפת 2027 הסופית

בתיקייה `2027/` נמצאות 90 התמונות המאושרות:

- `dN-hero.webp` — תמונת שער לתחום N (1600×900)
- `dN-a0M.webp` — תמונת כתבה קצרה לפי מזהה מדויק (1200×800)

השיוך החי נמצא ב־`2027/manifest.json`. אותה תמונה משמשת בעברית ובערבית.

## קבצים ישנים

קבצי Unsplash בשמות נושאיים (`watch.webp` וכו') נשמרו לתיעוד ואינם משויכים למעטפת הסופית.
